## Task Naming Convention

Use this format in ClickUp:

```
[PHASE]-[NUMBER]: [Description]
```

**Phases:**
- `FND` = Foundation (Weeks 1-2)
- `SETUP` = Setup (Weeks 1-2)
- `CHAT` = Chat UI (Week 3)
- `AGENT` = AI Agent (Week 3)
- `MCP` = MCP Integration (Week 3)
- `DB` = Database (Week 4)
- `API` = API Development (Week 4)
- `PERF` = Performance (Week 4)
- `DEPLOY` = Deployment (Week 4)
- `BUG` = Bug Fixes (Week 5)
- `UX` = User Experience (Week 5)
- `FEATURE` = Features (Week 5)
- `DOCS` = Documentation (Any week)
- `CODE` = Code Quality (Any week)
- `TEST` = Testing (Any week)
- `COMMIT` = Git Commits (Any week)

## Status Tracking

### Move tasks to "In Progress" when:
- ✅ You've started working on it
- ✅ You've committed code related to it
- ✅ You're not blocked

### Move tasks to "Ready for Review" when:
- ✅ Code is complete and committed
- ✅ Tested locally
- ✅ Waiting for peer review (or self-review)

### Move tasks to "Complete" when:
- ✅ Code is reviewed and merged
- ✅ Feature is live (deployed or tested locally)
- ✅ Documentation is updated
- ✅ No known issues

---

## Weekly Rhythm

### Monday Morning
- Review board status from last week
- Move completed tasks to "Complete"
- Plan this week's priorities
- Add new tasks if scope changed

### Tuesday-Thursday
- Work through "In Progress" tasks
- Move completed work to "Ready for Review"
- Update estimates if tasks are larger than expected

### Friday Afternoon
- Wrap up week's work
- Move final tasks to "Complete"
- Review velocity (hours planned vs. actual)
- Plan next week's priorities

## Screenshots for Submission

When taking ClickUp screenshot for submission:

1. **Full-screen view** - Show all columns and tasks
2. **All columns visible** - Backlog, In Progress, Ready for Review, Complete
3. **Assignees visible** - Names or avatars showing who worked on tasks
4. **URL bar visible** - Proof it's from your workspace

## Import to ClickUp

1. Create a new **List** named `Digital Twin - Weeks 1-5`
2. Create these **custom fields:**
   - Status (dropdown: Backlog, In Progress, Ready for Review, Complete)
   - Priority (dropdown: P0, P1, P2)
   - Phase (dropdown: FND, SETUP, CHAT, etc.)
   - Hours (number)

3. Manually add tasks from this template OR use ClickUp's CSV import

4. Assign tasks to team members

5. Set target completion dates for each task
